独立运行，本页不需要 AstrBot。

先配置模型

先填聊天接口，再选择能看视频、图片和音频的模型。视频接口留空时使用同一地址和密钥，模型名称仍需填写。

视频使用另一家接口

更换聊天风格后使用独立的历史范围，避免继续引用旧风格的对话。

限制一条作品的原视频或全部原图总大小。出现媒体总大小超限时，可在这里调大；保存后新下载立即生效。

180 秒为 3 分钟；0 表示不限时长。超限或无法确认时长时不下载，并提示换一个视频。图文不受此项限制。

0 表示清理全部已用完的缓存。只处理当前目录中本程序管理的媒体，正在使用的文件会跳过；聊天记录、观看转述和登录资料保留。程序重新启动后重新计时。

组件状态位置与说明

登录与私信

请在本页打开的专用浏览器窗口中操作。你平时用的浏览器即使已经登录、打开了私信，也不代表本程序已经连接。

  1. 先保存上方聊天和视频模型设置，确认依赖可用。
  2. 点击“打开登录窗口”，在弹出的窗口登录机器人的抖音账号，完成可能出现的验证码。
  3. 在同一窗口点击抖音的“消息”，再点开要回复的那位用户，直到能看到聊天记录和输入框。只打开首页或消息列表还不够。
  4. 首次接入时，目标会话里需要有双方的消息。如果机器人账号从未发过消息，请先在这个窗口手动回一条普通文字，便于确认收发方向。
  5. 回本页点击“绑定当前私信”，核对对象名称，再点“开启回复”。已有消息只作为历史，旧消息不会补回。
  6. 用自己的账号给机器人发一条新的纯文字消息；确认能回复后，再分享视频或图文。

日常使用不必重复绑定，也不用一直把浏览器放在前台；请保持专用窗口里的目标私信打开。需要更新状态时，点右上角“刷新状态”。

关闭窗口后怎么恢复？为什么还没有回复？

只关了私信面板：在专用窗口重新点击“消息”并进入已绑定的会话，回本页刷新状态。回复已暂停时再点“开启回复”；同一对象不必重新绑定。

整个专用窗口都关了：回本页点“重开登录窗口”。程序会尝试恢复已绑定的会话；没有恢复时，请手动进入目标私信，确认对象后再开启回复。请勿仅凭浏览器弹出，就认为私信已经就绪。

显示“正在处理消息”：视频、图文会先下载和识别，再生成回复，比纯文字耗时更长。期间可能临时打开作品标签页，正常结束后会关闭这个临时页；请保留原来的私信页。请稍候并刷新状态，不要反复绑定或重开窗口。

只显示“回复开关已开启”或有错误提示：还需按提示完成登录、验证码或进入目标私信。显示“正在监听新私信”后，用自己的账号发送一条新消息验证；旧消息不会补回。

要换账号或私信对象：先暂停回复，进入新的目标私信，再绑定并核对白名单，最后开启回复。
